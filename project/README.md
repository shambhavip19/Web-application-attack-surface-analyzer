Web Application Attack Surface Analyzer

This repository contains a passive web application information analyzer for academic use. It performs only normal HTTP/HTTPS requests to publicly accessible resources and analyzes responses.

Structure

project/
├── frontend/  (React + Vite + Tailwind)
├── backend/   (FastAPI + scanner)
└── reports/   (generated PDFs)

See backend/README.md and frontend/README.md for running instructions.
